# 步骤截断（dsh-step-editor）

按**步骤**修剪模型可见上下文。删除不会改写会话日志：插件追加一个 surface 替换事件，让后续请求不再包含被选中的消息；原始记录与聊天记录仍然保留。

## 用途

一个典型场景：某一步读取了大量图片，请求体积超过网关上限，而该错误不被 DSH 识别为 context-overflow，compaction 不会触发。中断当前轮再发新指令，仍会把同样的历史重新发出去，会话卡死。

用本插件从出问题的步骤截断到会话末尾，下一轮请求就会重新落回限额内，原会话可以继续用。

## 用法

```
/truncate --dry                  # 列出各步的字节数、图片数与状态，不写入
/truncate <轮次> <步骤>          # 从该步起截断到会话末尾
/truncate <轮次> <步骤> --silent # 本次不向模型留下任何替代消息
```

- 执行前需要先停止当前轮（Agent 空闲）。
- 计算单位是步骤：一次模型请求加它调用的工具，因此工具调用/结果不会被拆开。
- 截断不可撤销；需要保留退路时，先在该步之前分支会话。

## 设置

设置页提供「墓碑模式」：

- `visible`（默认）：模型会在被移除的位置看到一行说明。
- `silent`：模型完全看不到被移除的内容，也不会看到说明。

## 限制

- 只支持"从某步到会话末尾"的后缀截断，不支持删中间步骤。
- 日志体积不会因为截断而变小；被移除的图片仍然留在会话文件里，只是不再进入请求。
- 聊天记录仍显示原始消息（审计用途），只有模型可见历史被改写。
- 轨迹页的行内按钮不在本版本范围内；操作入口是 `/truncate` 命令。

## 安装

在插件管理器的安装框输入 `dsh-step-editor`（npm），或粘贴 `https://github.com/WhiteBaddy/dsh-step-editor`（GitHub）；安装后刷新页面，会话头部出现「步骤」按钮。

支持 DSH `0.2.2-rc.1` ~ `0.2.2-rc.5`。

当前版本：v0.1.1（命令、面板、分支、设置页均已实现；选某轮第 1 步即整轮删除）。
