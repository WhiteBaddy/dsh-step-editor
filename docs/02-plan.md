## 2. 阶段 S4-01：Host 基础

**阶段目标**：在测试 profile 内，对任意 fixture 会话执行 `/truncate <turn> <step>`，能在不修改 DSH 本体的前提下把该步起的消息从模型可见历史移除；所有失败路径不写入任何事件。

**范围**：FR-01、FR-05、FR-06、FR-09、FR-10（Host 侧）；NFR-01~NFR-05。

### 任务清单

| 编号 | 任务 | 人日 | 依赖 |
| --- | --- | --- | --- |
| T1.1 | bundle 骨架：`package.json`、`cordis.patch.yml`、`locale/{zh,en}.json`、icon、README | 0.5 | — |
| T1.2 | 步骤索引 fold：`stepEditor` 的 `init/apply/view` 与状态契约 | 1.0 | T1.1 |
| T1.3 | 遮蔽追踪：用替换事件 `sourceEventSeqs` 标记被遮蔽消息；`stateVersion: 1` | 0.5 | T1.2 |
| T1.4 | 范围推导与校验：idle、步骤存在/未遮蔽、整步、节点 0、端点成员 | 1.0 | T1.2、T1.3 |
| T1.5 | 替换写入：visible（user 墓碑 + 自定义 source）/ silent（空 system 节点），`sourceEventSeqs` 全覆盖 | 1.0 | T1.4 |
| T1.6 | 命令 `truncate`：语法、`--dry`、`--silent`、错误码、用法文案 | 1.0 | T1.4、T1.5 |

| T1.9 | Host 模块 README 与配置说明 | 0.5 | T1.6 |

**交付物**：可安装的 Host-only bundle；fixture 与测试脚本；基准数据；Host README。

**验收标准**（可执行）：

1. `node --test` 全绿，覆盖 TC-01~TC-03、TC-08~TC-11、TC-16、TC-17、TC-19。
2. 测试会话上执行 `/truncate --dry` 输出与投影一致，且日志长度不变。
3. 执行 `/truncate` 后 `deriveMessages()` 不再包含被删区间，前一条历史不变。
4. 每个错误码都有一个反例，且反例执行后日志长度不变。
5. 1000 步 fixture 冷 fold < 100 ms（实测数字写入 03 文档）。
6. 禁用插件后，含替换事件的会话仍能 open / resume。

**风险**：

| 风险 | 缓解 |
| --- | --- |
| 投影与真实 surface 不一致（D-06） | TC-02 对拍；不一致即回退到「只按本插件替换追踪」并登记 ISSUE |
| 命令名冲突（ISSUE-003） | T1.6 启动时检查；冲突改用 `step-truncate` |
| silent 模式在真实会话的行为未知（D-03） | 仅在一次性测试会话启用；TC-09 通过前不写进用户文档 |
| 1000 步 fold 不达标 | 同引用短路 + 只存必要字段；仍不达标则面板改为窗口化 |

**本阶段预期遗留问题**：

| --- | --- | --- |
| ISSUE-003 | `truncate` 命令名是否与现有命令冲突 | S4-01 T1.6 前 |
| ISSUE-004 | silent 模式在真实会话的端到端表现未验证 | S4-02 结束前（TC-09） |

**人日拆解**：编码 4.0（T1.2–T1.6）/ 测试 1.5（T1.7、T1.8）/ 文档 0.5（T1.9）/ 联调 0.5 / 缓冲 0.5 = **7.0**。

**验收标准**（可观察）：

1. 在 `127.0.0.1:15999` 的 GUI 上，同一会话切 Chat / Trajectory，头部按钮都可见（TC-04）。
2. 面板行数与投影一致，数字一致（TC-05）；加载更早可用（TC-06）。
3. 打开确认框前后日志与 surface 不变（TC-07）。
4. 执行 visible 截断后，面板标记"已移除"，下一轮请求成功（TC-08、TC-10）。
5. 分支产生子会话并自动打开，父会话不变（TC-12、TC-13）。
6. 设置页切换 `tombstone` 后，下一次截断的替换形态随之变化（TC-14、TC-15）。
7. 错误路径有中文文案与下一步动作（TC-11 的 UI 侧）。
8. 重载页面后面板状态从日志重建（TC-18）。

**风险**：

| 风险 | 缓解 |
| --- | --- |
| 头部浮层被裁剪（R-13） | 确认框一律 portal 到 body；在窄屏验证 |
| 投影更新与面板不同步 | 只读投影 + 命令结果触发一次刷新；TC-05 断言 |
| 分页后累计计算错位 | 累计只按投影全量算，分页只影响展示 |
| 设置表单未自动生成（ISSUE-002/P-04） | T2.7 前先做 30 分钟验证；不成立则用 `settings.section` 自定义面板 |
